luopan(罗盘)

一款旅游行程规划 skill。排程前先问清预算和范围,事实数据带来源,交付前自检。

两步安装 GitHub 仓库

特性

01

必问预算

预算没确认前,只输出问题清单,不出行程草稿。

02

范围红线

行程只覆盖你指定的地方,不擅自加城市。环线跨出范围时说明原因,另给一版严格替代,由你定。

03

来源分级

票价、开放时间这类数字优先官方渠道;自媒体和野榜只当线索,标"需官方确认"。每条数据带来源和查询日期。

04

体量定负荷

浏览时间之外,再留出排队、交通、吃饭、拍照的余量;顶流园区独占一天;自驾车程也算进当天负荷。

05

输出前自检

交付前重读规则,逐条填自检表(带证据)。行程越长规则越容易走样,这一步兜底。

06

输出包含

逐日行程表、预算估算(经济/舒适两档)、交通和住宿建议、景点与美食清单(含避雷)、二次确认清单、数据来源索引。

迭代记录

这些规则不是 skill 自动总结的,是每版行程排好后由作者本人对照真实需求挑错,错处写回规则。完整记录见 ITERATIONS.md。

安装

支持插件系统的客户端终端,两步装好:

  1. 注册插件源:plugin marketplace add saudademjj/luopan
  2. 安装 skill:plugin install travel-planner
本地调试用本地路径:plugin marketplace add /path/to/luopan。也可以把 skills/travel-planner 手动复制到你的 skills 目录。

使用

直接说需求,skill 自动触发;也可以显式调用。

  • 「帮我规划去苏州 5 天,带爸妈」
  • 「北京 7 天 6 晚,情侣,预算中等」
  • 「伊犁自驾 9 天,5 人,从乌鲁木齐出发」
第一步先收集需求(预算必问),确认后才联网调研、排行程。

输出示例:伊犁 10 天自驾环线(含独库公路北段),含规则自检表和数据来源索引。
