# Code of Conduct

## Our standards

This project is built from recorded mistakes: every rule came from a real itinerary that failed a real need. Discussion should follow the same standard.

- **Be constructive.** Criticism is welcome when it points at a concrete case and a concrete fix.
- **Be evidence-based.** Claims about destinations, prices, or policies should cite a source, the same way itineraries do.
- **Be patient with iterations.** Rules change through recorded rounds, not by majority vote in a thread.
- **Respect boundaries.** No harassment, no personal attacks, no doxxing.

## Enforcement

Instances of unacceptable behavior may be reported to the maintainer via the private security reporting channel or by opening an issue marked "conduct". Reports are reviewed within 7 days. Repeated or severe violations lead to a block.

## Scope

This code of conduct applies to issues, pull requests, and any discussion attached to this repository.
